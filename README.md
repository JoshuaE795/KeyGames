# Orangutan OS

A collection of the original Python/Turtle mini-games, launched from one black-and-white hub.

## Games

- Hangman
- Typing Test
- Typing Game
- Wordle
- Tic-Tac-Toe

## Run

```bash
python main.py
```

## Requirements

- Python 3
- Tkinter
- Turtle

Updated over time with new mini games
