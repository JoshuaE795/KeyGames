# Orangutan OS

A collection of the original Python/Turtle mini-games, launched from one black-and-white hub.

## Games

- Hangman
- Typing Test
- Typing Game
- Wordle
- Tic-Tac-Toe

## Run

```bash
python main.py
```

The hub launches each game as its own Python process. The game source files are kept in `games/` and are intentionally left in their original form rather than being refactored into a shared framework.

## Requirements

- Python 3
- Tkinter
- Turtle

The games also expect their original resource files to live beside them in `games/`.
